# Password visibility controls

## Changes
- Add a bilingual “See password / Pokaži geslo” control to every password-entry login or unlock screen.
- Keep every affected password hidden by default and change the control to “Hide password / Skrij geslo” while visible.
- Cover marshal account login and registration, field entry, mission/marshal/master unlock prompts, and archive admin unlock.
- Leave password creation and account field-password settings unchanged unless they are part of a sign-in form.
